# Lakshana S - UI/UX Design Portfolio

A static portfolio site split into HTML, CSS, and JavaScript files.

## Run locally

Serve this folder with a local static web server for all portfolio interactions. The cursor-heart trail also works when opening `index.html` directly, but some browsers block the page's ES-module scripts under `file://`.

## Profile

The portfolio reflects Lakshana's resume and the Talview UI/UX Intern role: Figma, user research, user flows, wireframes, mockups, interactive prototypes, responsive UI, reusable components, usability, collaboration, and problem-solving.

Design tools listed are those present in the resume: Figma, Adobe Photoshop, Adobe Illustrator, and Canva. Sketch, Balsamiq, and InVision are not listed as skills because the resume does not confirm experience with them.

The About section features Lakshana's beach portrait and an NCC cadet photo with a short personal caption.

Subtle floating scrapbook doodles decorate the main sections. On fine-pointer devices, a few respond gently to mouse movement; animations respect reduced-motion preferences and are minimized on small screens.

## Portfolio themes

Use the theme menu to the left of About in the navigation to switch among Blush Scrapbook, Midnight Elegance, Sage Garden, and Ocean Breeze. The selected palette is saved in browser `localStorage` and restored on the next visit; new visitors see Blush Scrapbook by default. Theme switching also works when opening `index.html` directly.
